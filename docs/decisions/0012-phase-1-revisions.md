# 0012. Revisions after Phase 1 verification

**Decision:**
- mattpocock-skills is declared as a plugin `dependencies` entry; deps.lock.toml pins SHAs for non-plugin sources (rederive).
- The `saw` CLI ships in the plugin's `bin/`; the global instruction fragment is a skill plus bootstrap, not a plugin-root CLAUDE.md (it would not load).
- Hooks live in `hooks/hooks.json` (plugin agents ignore per-agent hooks).
- Model routing, effort and turn caps are set in agent frontmatter, generated by `saw sync` from `[models]`; `single` mode uses `CLAUDE_CODE_SUBAGENT_MODEL`.
- `saw run` is implemented as a PreToolUse hook that rewrites check commands to return failures only.
- Claude evals use `claude plugin eval`; `saw eval` wraps it and adds Codex.
- Code-map fallback when Trail is off: official LSP code-intelligence plugins.
- AGENTS.md is never auto-generated; context files stay under 100 lines (global under 200).
- Hard budgets in headless runs use `--max-budget-usd`; interactive hard budgets use the Stop/PreToolUse hooks.
- Subagent teams off by default (about 7x token cost).

**Why:** Claude Code already provides these mechanisms (see [[RESEARCH]] section 7); reusing them removes custom code and maintenance.
