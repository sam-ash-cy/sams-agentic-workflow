# Prompts

Paste these into Claude Code (or any agent). Each one starts the router, so the tier, playbook and checks still apply. Fill in the `<...>` parts.

| Prompt | Use when |
|---|---|
| [start-project](start-project.md) | a new repo, or one without workflow.toml |
| [start-feature](start-feature.md) | building something planned |
| [debug](debug.md) | something is broken, failing or slow |
| [stuck](stuck.md) | the same check keeps failing, or the agent is going in circles |
| [resume](resume.md) | picking work back up in a fresh session |
| [review](review.md) | before opening or merging a PR |
| [handoff](handoff.md) | stopping mid-task |
