# Project docs

This folder is an Obsidian-compatible vault: open it as a vault, or read it on GitHub.

- [[conventions]]: how code is written here (enforced by tests where possible)
- [[glossary]]: the project's words, one definition each
- `decisions/`: ADRs, never edited, only superseded ([[decisions/0000-template|template]])
- `features/`: one note per shipped feature ([[features/_template|template]])
- `plans/`: stage plans; archived after merge
- `learnings/`: what was decided, ruled out, and what to watch out for
